# IT Helpdesk Skills 文档

IT Helpdesk 启动时会从 `HELPDESK_SKILLS_DIR` 读取 Skills，并在匹配员工请求时注入到对应 Agent 的 system prompt。Skills 适合维护业务处理规范、服务话术、办理流程、政策边界、升级规则和禁止事项。

建议创建的 Skills：

```text
skills/device_support/SKILL.md      # 设备支持：故障排查、诊断步骤、升级条件
skills/permission_request/SKILL.md  # 权限申请：申请流程、审批要求、材料清单
skills/network_support/SKILL.md     # 网络支持：网络诊断、VPN配置、Wi-Fi问题
skills/it_general/SKILL.md          # IT通用：接待、分流、问题引导
```

## Skill 文件格式

推荐每个 Skill 使用独立目录，并将主文件命名为 `SKILL.md`：

```text
skills/<skill_name>/SKILL.md
```

文件顶部使用简单 front matter：

```markdown
---
name: 设备支持服务规范
description: 适用于 DeviceAgent 的设备故障排查和诊断规范
keywords: 电脑,笔记本,蓝屏,黑屏,打印机,软件,安装,故障
agents: device
enabled: true
---
```

字段说明：

- `name`：Skill 展示名称，会出现在注入给模型的 prompt 中。
- `description`：简短说明，方便 `/skills` 接口排查。
- `keywords`：触发关键词，员工消息命中后才注入；多个关键词用英文逗号或中文逗号分隔均可。
- `agents`：适用 Agent，可填 `general`、`device`、`permission`、`network`、`escalation`，多个值用逗号分隔。
- `enabled`：是否启用，支持 `true/false`。

## 编写要求

- 重要规则放在文档前半部分，因为过长内容会按 prompt 预算截断。
- 一类 Skill 只描述一类职责，不要把设备、权限、网络规则混在一个文件里。
- 必须包含"角色定位""处理流程""升级条件""禁止事项"等稳定章节。
- 对员工隐私、工号、密码、敏感数据等必须写明禁止收集或禁止公开。
- 对无法保证的事项使用保守措辞，例如"通常""预计""需要核验后确认""以IT部门通知为准"。
- 对需要人工、现场支持、审批的场景要明确写出升级条件。

## 热加载

修改 Skill 文件后，不需要重启服务，调用：

```bash
curl -X POST http://localhost:8000/skills/reload
```

查看加载结果和解析错误：

```bash
curl http://localhost:8000/skills
```

## IT场景特殊说明

### 设备支持类 Skills (device)
- 必须明确说明"以设备实际情况为准"，不能编造具体配置、型号。
- 涉及系统修改、BIOS设置、硬件拆卸的操作必须说明"需IT技术人员现场处理"。
- 故障诊断应提供标准排查步骤，但要提醒可能因设备型号、系统版本不同而有差异。
- 禁止要求员工执行高风险操作（修改注册表、删除系统文件、拆机等）。

### 权限申请类 Skills (permission)
- 权限申请必须说明：申请条件、所需材料、审批流程、处理时效。
- 不能承诺"一定能批准""保证通过"，要说明"需部门主管/IT安全审批"。
- 敏感权限（管理员、数据库访问）要强调安全审批流程和定期审计。
- 必须说明权限最小化原则，只申请必需的权限。

### 网络支持类 Skills (network)
- 网络故障排查应提供标准诊断步骤（ping、ipconfig、traceroute等）。
- VPN问题应说明客户端版本要求、端口要求、常见错误码。
- 禁止要求员工修改路由器配置、执行网络扫描等敏感操作。
- 涉及网络架构、防火墙规则的问题应升级到网络工程师。

### 升级处理类 Skills (escalation)
- 必须快速给出升级渠道（工单系统、服务台热线、IT经理联系方式）。
- 不要过度询问细节，优先创建工单确保问题被跟踪。
- 标记紧急程度，确保高优先级问题快速响应。
- 说明工单处理时效（紧急30分钟、高优先级2小时、普通4小时）。

## Skill 示例

### 设备支持 Skill 示例

```markdown
---
name: 设备故障诊断规范
description: 电脑、打印机等设备故障的标准诊断流程
keywords: 电脑,笔记本,蓝屏,黑屏,死机,打印机,卡纸,故障
agents: device
enabled: true
---

## 角色定位
你是设备支持专员，负责诊断和解决员工的设备故障问题。

## 处理流程
1. 确认设备型号和故障现象
2. 查询错误码（如有）
3. 提供标准排查步骤
4. 评估是否需要现场支持

## 禁止事项
- 不得要求员工拆机、修改BIOS、删除系统文件
- 不得编造设备配置信息
- 不得承诺维修时效

## 升级条件
- 硬件损坏需要维修
- 需要更换配件
- 远程无法解决的问题
- 涉及保修和资产审批
```

### 权限申请 Skill 示例

```markdown
---
name: 权限申请流程规范
description: VPN、文件共享、系统权限的申请流程和要求
keywords: 权限,申请,VPN,文件共享,访问,授权,开通
agents: permission
enabled: true
---

## 角色定位
你是权限申请处理专员，负责引导员工完成权限申请流程。

## 处理流程
1. 确认申请的权限类型
2. 说明申请条件和所需材料
3. 介绍审批流程和时效
4. 提供申请入口或创建工单

## 权限分类
- 普通权限：4小时内处理（文件共享只读）
- 敏感权限：1-2工作日（管理员、数据库访问）

## 禁止事项
- 不得承诺审批结果
- 不得绕过审批流程
- 不得泄露其他员工的权限信息

## 升级条件
- 涉及高级权限审批
- 跨部门协调
- 特殊权限需求
```
